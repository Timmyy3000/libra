# Libra Web

This is the Next.js app for Libra.

## Getting started

Run from the repo root:

```bash
bun install
bun run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Purpose

`apps/web` holds:
- the landing page
- the product UI
- the upload, casting, generation, and playback flows

The repo root README is the real project entry point. This file exists just so the app package is not carrying the default Next.js boilerplate nonsense.
